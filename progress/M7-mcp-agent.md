# M7：MCP 与 Agent

**阶段目标：** 提供本地 MCP Host 和 AI 助手，让用户通过可审计、受授权的工具调用查询和操作 CreatorRelay 业务数据。

**用户价值：** 用户可用自然语言查询账号/作品/数据、生成内容或创建任务，并能在每次工具执行前后看清调用了什么、影响谁、发生了什么。

## 前置条件

M2–M6 已提供稳定 Core Service/API 和相应权限语义；模型 Provider 的 BYOK 配置与隐私告知（M5）已完成。MCP Server 不得绕过 Core 直接连接 SQLite 或读取完整凭据。

## 范围

- 本地 MCP Host/Client 生命周期及本地 stdio Server 管理。
- 工具注册、Schema 校验、超时/取消、健康检查、崩溃重启和调用日志。
- 平台工具与内部工具统一注册，例如账号信息/指标、作品列表/详情、Analytics 趋势、Studio 搜索/创建/适配、Publishing 创建任务。
- Studio 工具显式支持 `video`、`image_text`、`rich_article`、`plain_article`，并按形态校验正文、媒体顺序、封面和必填元数据。
- Assistant 对话历史、模型选择、工具调用过程、参数摘要、结果和错误显示。
- Read / Write / External Action 权限分级。
- 云端模型数据披露、发送范围选择、敏感值脱敏；本地模型端点按配置接入。
- 人工确认及批量发布目标预览。

## 功能要求

1. 工具输入按版本化 JSON Schema 验证；工具必须标明只读、写入或外部副作用等级。
2. Read 工具按用户设置授权；Write 操作遵循明确授权策略；发布、删除和公开资料变更等 External Action 每次执行前确认。
3. 确认页面展示工具名、内容形态、目标平台和账号、参数摘要、预期副作用；视频/图文展示媒体文件与顺序摘要，批量发布需展示完整账号和内容清单。
4. MCP Server 通过受控 Core API 执行业务操作，不持有数据库连接和完整凭据访问权。
5. 超时、取消、Server 崩溃均返回可见状态并记录脱敏日志；不把失败工具调用伪装成成功。
6. 多 Agent 复杂编排不纳入 MVP；首期工作流可由用户发起并逐项授权。
7. 发送到云端模型的上下文遵循用户选择的数据范围；API Key、完整 Cookie、Token 不得进入 Prompt、工具输出或日志。
8. 内容工具不得接受任意本地文件路径或原始凭据；媒体通过 Core 资产服务按内容 ID/素材 ID 访问。
9. 未提供当前形态必需载荷（如视频文件、图文顺序、文章正文）时，工具在产生本地写副作用或外部请求前失败。

## 验收标准

| ID       | 验收场景       | 通过条件                                                                                         |
| -------- | -------------- | ------------------------------------------------------------------------------------------------ |
| M7-AC-01 | MCP 生命周期   | 应用启动后可启动/停止本地测试 MCP Server；健康状态可见，异常退出可检测且可按策略重启。           |
| M7-AC-02 | 工具发现与校验 | Host 能发现测试只读工具及其 Schema；合法参数成功调用，缺少/非法参数在执行前被拒绝。              |
| M7-AC-03 | 业务边界       | 工具通过 Core Service 查询测试账号/作品；测试证据确认 MCP Server 无直接 SQLite 和凭据读取通道。  |
| M7-AC-04 | 助手调用可见   | Assistant 展示模型、工具名、目标账号、参数摘要、结果和失败原因；对话重开后按产品规则可恢复历史。 |
| M7-AC-05 | 写操作授权     | 创建本地内容草稿或发布任务前按配置执行确认/授权，并显示内容形态；拒绝后没有产生业务副作用。      |
| M7-AC-06 | 外部操作确认   | 发布/删除类工具每次执行前展示完整目标与最终内容，用户拒绝后目标平台未收到操作请求。              |
| M7-AC-07 | 多目标发布安全 | 批量发布确认包含每个平台账号、内容形态及对应平台稿；确认后按独立任务执行，部分失败准确呈现。     |
| M7-AC-08 | 超时与取消     | 对挂起的工具调用执行超时/取消后，UI 显示对应状态，不继续重复执行；其他工具可继续使用。           |
| M7-AC-09 | 隐私控制       | 未被选择的正文不发送至云端模型；发送前展示目标服务商/内容范围；测试凭据不出现在模型请求或日志。  |
| M7-AC-10 | MCP 调用审计   | 调用日志可定位调用时间、工具、内容形态、脱敏参数摘要、结果状态和错误；不含敏感值。               |
| M7-AC-11 | 四类内容工具   | 通过工具分别创建/更新视频、图文、图文文章和纯文章草稿；返回 ID 与形态正确，重启后内容包可恢复。  |
| M7-AC-12 | 形态载荷校验   | 视频缺少视频文件、图文顺序为空或文章正文缺失时，工具在写入/发布前拒绝，并返回字段级错误。        |

## 不在本阶段

- 复杂多 Agent 自主编排和无监督长期任务。
- 未经确认的自动发布/删除。
- 外部 MCP 服务自动获得本地账号或凭据权限。
