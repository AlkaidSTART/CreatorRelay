# M5：内容工作室

**阶段目标：** 将本地内容工作区扩展为端到端创作空间，支持视频、图文、图文文章和纯文章四类内容的形态专属编辑、AI 辅助、平台稿生成和人工检查。

**用户价值：** 用户不需要先把所有创作都写成 Markdown 文章；可以直接准备视频或图集，也可以编写图文文章或纯文章，再把同一份主内容适配到实际支持该形态的多个平台。

**状态：** 需求拆分完成；实现状态待项目跟踪。

## 范围

- 统一内容库和四类新建入口，默认顺序为：视频、图文、图文文章、纯文章。
- 三栏式 Studio：左侧内容/文件夹/标签/素材/形态筛选，中栏形态专属编辑，右侧 AI/检查/平台适配。
- 视频内容编辑：导入/替换视频、预览、封面、标题、简介、标签及可选字幕/章节；不包含专业时间线剪辑。
- 图文内容编辑：多图导入、拖拽排序、设封面、替换/删除、逐图说明、标题/短文案和最终卡片预览。
- 图文文章编辑：Markdown 正文、内联图片/视频、图片说明、封面、分栏预览和平台适配。
- 纯文章编辑：Markdown 正文、标题、摘要、标签和阅读预览。
- 通用自动保存、快捷键、Slash Commands（文章类）、版本历史和保存失败保护。
- 标题、摘要、润色、结构优化、语气转换、内容检查和自定义 Prompt 等 AI 能力，按内容形态提供不同操作与输入范围。
- BYOK 模型供应商与 OpenAI Compatible 配置；凭据由 M3 凭据服务保存。
- 从主内容按兼容的平台/账号生成一个或多个独立 Platform Draft；对比、编辑和重新适配。
- 平台格式、长度、数量、尺寸、时长与素材要求检查；未验证规则明确标记为未检查。
- 从平台稿发起发布准备流程（实际任务执行归 M6）。

## 功能要求

1. 新建内容时必须选择 `ContentKind`；界面默认顺序为视频、图文、图文文章、纯文章，不得只提供“新建文章”入口。
2. 视频编辑器须允许导入一个主视频、设置封面、编辑标题/简介/标签和预览；视频内容本体不要求 Markdown 正文。
3. 图文编辑器须持久化图片顺序和封面归属，支持逐图说明和短文案；图片数量、尺寸和顺序在预览与平台稿中保持一致。
4. 图文文章和纯文章以 Markdown 正文为权威来源；图文文章须保留内联媒体位置、图片说明和封面。
5. 同一内容形态下的自动保存、编辑、预览和重新打开行为一致；保存失败不丢弃编辑内容，也不显示虚假的已保存状态。
6. 修改主内容后比较生成版本与当前版本，包括正文、封面和媒体顺序；不得自动覆盖已有手动修改的平台稿，用户可选择保留或重新适配。
7. 只为当前 `ContentKind` 和账号展示可直接适配/发布的平台能力；未验证或不支持时明确显示原因，不把平台名称当作格式保证。
8. AI 生成操作必须明确输入范围、发送到的模型服务商和内容形态；视频/图文可发送用户选中的文案和素材元数据，不得默认上传整个媒体库或工作区。
9. AI 结果在用户明确保存/替换前不覆盖现有正文、图片顺序、封面或视频元数据；至少支持预览差异并撤销本次操作。
10. 平台检查结果须区分硬性错误、警告和未支持检查，并按形态检查正文、图片/视频格式、媒体数量、封面和必填字段。
11. 每个 Platform Draft 关联唯一主内容及生成时版本标识；平台稿独立保存，编辑一个平台稿不修改主内容或其他平台稿。
12. 跨形态派生必须生成新的 Content Draft 并记录来源；MVP 不承诺无损自动转换，也不得静默改变原内容形态。

## 验收标准

| ID       | 验收场景       | 通过条件                                                                                                              |
| -------- | -------------- | --------------------------------------------------------------------------------------------------------------------- |
| M5-AC-01 | 四类新建入口   | 新建面板按视频、图文、图文文章、纯文章显示；四类内容创建后形态正确，重启后编辑视图与内容一致。                        |
| M5-AC-02 | 视频编辑       | 导入视频和封面，填写标题/简介，打开预览并重启；视频文件、封面和元数据仍关联，不要求生成空 Markdown 正文。             |
| M5-AC-03 | 图文编辑       | 导入至少三张图片，调整顺序、设置封面、填写短文案和逐图说明；重启与预览后顺序、封面和说明一致。                        |
| M5-AC-04 | 文章编辑       | 图文文章可插入内联图片并显示说明；纯文章可编辑 Markdown；两类正文保存后重启可恢复，正文不由 SQLite 覆盖。             |
| M5-AC-05 | 自动保存失败   | 模拟磁盘只读/写入失败时，编辑器保留未保存内容并显示可操作错误；视频、图文和文章编辑器均不显示虚假的已保存状态。       |
| M5-AC-06 | 模型配置       | 可添加 BYOK 供应商/兼容端点、选择模型、测试连接和切换默认模型；连接失败明确显示原因。                                 |
| M5-AC-07 | 隐私告知       | 发起云端 AI 操作前，界面可见内容形态、将发送的正文/文案/素材元数据和目标服务商；未确认时不发出模型请求。              |
| M5-AC-08 | 形态化 AI 辅助 | 对视频生成标题/简介，对图文生成短文案，对图文文章/纯文章生成标题或摘要；结果可预览、应用或丢弃，未应用不改写主内容。  |
| M5-AC-09 | 平台选择过滤   | 测试适配器声明支持图文但不支持视频；视频内容的目标列表不提供该能力为支持，图文内容可选择，并显示准确能力状态。        |
| M5-AC-10 | 多平台适配     | 对同一份主内容选择两个兼容目标生成两份独立平台稿；修改其中一份不改变另一份和主内容，图片顺序/封面或视频元数据不丢失。 |
| M5-AC-11 | 版本差异保护   | 创建平台稿后修改主内容正文、封面或媒体顺序，再打开平台稿时提示源内容已变化；手动修改不丢失，并能选择保留或重新生成。  |
| M5-AC-12 | 内容检查       | 对设置了形态规则的测试平台稿正确报告通过/失败；未提供规则或未验证的检查明确标记为未检查，不把未知写成通过。           |
| M5-AC-13 | 凭据与日志     | 模型调用成功及失败路径均不在日志、SQLite 或 UI 调试输出中泄露测试 API Key。                                           |

## 不在本阶段

- 专业视频时间线剪辑、转码工作台、专业图像处理或设计画布。
- AI 视频生成、自动剪辑和无确认的自动换图。
- 跨四类形态的高保真自动转换；只要求创建可追溯的派生草稿。
- MCP Agent 自主规划、工具调用和跨模块编排（M7）。
- 外部发布任务执行及发布状态管理（M6）。
- 团队协作和云同步。
