## 范围

- 按 PRD 建议顺序评估和接入更多平台：Bilibili/YouTube、小红书/抖音/快手、微信公众号/知乎、掘金/CSDN、微博。

- 平台 × 账号 × `ContentKind` 能力矩阵、版本支持表和能力回归测试。

- 性能、可靠性、数据备份恢复和跨操作系统兼容性改进。

## 功能要求

1. 新平台进入开发前完成平台准入记录，注明官方接口/政策来源、验证日期、账号类型及不支持事项。
2. 能力矩阵按账号/平台/版本准确反映 `supported`、`unsupported`、`restricted`、`experimental`、`unavailable`；能力失效后及时降级。
3. 每个新增适配器复用统一账号、作品、指标、任务与凭据模型；视频、图文、图文文章、纯文章的读取/发布能力分别验证，平台特有字段放入有 Schema 的扩展部分。
4. 适配器测试覆盖分页、限流、过期授权、平台变更、超时、重复提交及部分可用情形。
5. 安装、升级和卸载遵循来源校验、用户授权、最小权限和故障回退策略；不受信任插件未具备经审查的强隔离前不得开放任意执行。
6. 新增平台自动发布仅在官方支持且政策允许并通过验证后开放；否则保持人工发布流程。
7. 版本升级兼容旧数据库、旧 Markdown/Frontmatter、内容包清单、历史发布任务和旧插件授权；不兼容时提供明确迁移/回退路径。

## 验收标准

| ID       | 验收场景     | 通过条件                                                                                                                 |
| -------- | ------------ | ------------------------------------------------------------------------------------------------------------------------ |
| M8-AC-01 | 平台准入     | 对每个新增平台有可追溯的官方接口/政策评估和验证结果；未验证能力明确标为未知/实验，而非支持。                             |
| M8-AC-02 | 兼容性       | 新适配器通过统一合约测试和已有适配器回归测试；失败时不影响其他平台插件。                                                 |
| M8-AC-03 | 能力呈现     | UI/MCP 返回平台及账号级能力状态；账号授权过期或平台接口不可用时状态降级并给出原因。                                      |
| M8-AC-04 | 平台数据差异 | 新平台作品和指标可映射到统一模型，并保留 `ContentKind`、原始内容类型/ID/字段、定义、单位和来源。                         |
| M8-AC-05 | 版本升级     | 从上一个受支持版本升级后，四类内容包、Markdown 正文、账号引用、任务记录和历史指标仍可读取；迁移失败可安全恢复。          |
| M8-AC-06 | 权限治理     | 插件升级引入新权限时要求重新审查；用户拒绝权限后插件不能调用该能力。                                                     |
| M8-AC-07 | 发布安全     | 未获官方支持或无法证明合规的平台不开放自动发布，并仍可通过人工辅助完成用户操作。                                         |
| M8-AC-08 | 插件市场决策 | 对外开放第三方市场前，完成威胁评估、安装来源/签名、强隔离、更新回滚、权限撤销和应急下架验收；未满足时保持封闭/受控试点。 |
| M8-AC-09 | 内容形态覆盖 | 每个新增平台分别记录视频、图文、图文文章、纯文章的读取/发布验证结果；未验证形态不得显示为支持。                          |

## 不在本阶段默认承诺

- PRD 列出的每个平台都必然可接入或具备相同功能。
- 第三方插件市场一定开放。
- 团队协作、云端同步、专业视频编辑和专业图像处理；这些需独立产品规划。

## 测试与交付

每个平台交付接入评估、平台 × 账号 × 内容形态能力矩阵、Adapter 版本和测试报告；生态层交付开发者文档、兼容性政策、权限变更及故障回退手册。覆盖合约、逐形态发布/读取、平台政策变更、跨版本数据迁移、权限升级和异常恢复测试。
