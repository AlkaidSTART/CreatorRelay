# M6：发布、同步与运营数据

**阶段目标：** 将四类平台稿、外部发布、作品同步和指标快照连成可追踪的运营闭环，同时允许不同平台按内容形态和账号能力缺省。

**用户价值：** 用户能按账号发布视频、图文、图文文章或纯文章，检查发布结果和失败原因，并在统一内容中心及数据视图中查看平台返回的作品与指标。

## 范围

- 从 Content Draft/Platform Draft 创建按“内容形态 × 平台 × 账号”拆分的独立发布任务。
- 分形态发布前检查、最终内容包预览、立即发布、平台支持时的定时发布及人工发布辅助。
- 视频发布包：视频文件、封面、标题、简介、标签及平台要求的字幕/章节等字段。
- 图文发布包：有序图片、封面、标题、短文案和逐图说明。
- 图文文章/纯文章发布包：Markdown 正文、媒体位置、封面（可选）及平台适配结果。
- 任务状态：`CREATED`、`VALIDATING`、`PENDING`、`SCHEDULED`、`PUBLISHING`、`SUCCESS`、`FAILED`、`CANCELLED`、`NEEDS_MANUAL_ACTION`。
- 每个平台/账号独立记录内容形态、执行时间、状态、结果、外部内容 ID、链接与错误原因。
- 外部作品读取/同步、统一 Content 列表、按四种形态筛选及作品详情。
- 账号与作品指标快照、平台原始指标名、定义、单位、来源和采集时间。
- Dashboard 总览及 Analytics 的账号、内容形态、内容、平台和时间趋势视图。
- 手动或按已验证策略触发同步；登录失效及部分同步失败的异常呈现。

## 功能要求

1. 多平台发布不是分布式事务；每个目标平台/账号是独立任务，单项失败不得改变其他任务结果。
2. 发布目标必须同时支持当前 `ContentKind`；无能力、未验证或不支持的形态不能以“可自动发布”呈现。
3. 发布前必须展示内容形态、平台、账号、最终内容包和执行方式；视频/图文需可核对文件和顺序，文章需可核对渲染正文。
4. 自动发布不支持或未验证时，任务进入 `NEEDS_MANUAL_ACTION`，提供完整发布包导出/打开平台等人工辅助；视频和图文不得退化为只复制文字。
5. 外部发布/修改动作需要用户确认；批量发布展示每个目标及对应内容包版本。
6. 超时导致结果不确定时，先查询平台作品或请求人工核对；不允许无限重试造成重复发布。
7. Adapter 返回的发布结果必须可追溯到内容形态、内容版本、目标账号和实际提交的媒体列表/顺序。
8. 同步以幂等键/外部平台 ID 去重；重复同步不能无提示地制造重复作品或历史快照。
9. 作品同步须把平台原始内容类型映射为 `ContentKind`，同时保留原始类型；无法确定时标记未知，不强制猜测。
10. 保留平台原始指标口径；仅在有明确字典定义时映射为统一指标。视频播放、文章阅读等不可在无说明时直接合并。
11. `FAILED`、`NEEDS_MANUAL_ACTION`、账号失效和部分同步失败都需显示可理解的原因及下一步操作。
12. 发布或同步任何阶段都不得静默丢失视频文件、图片顺序、封面或文章内联媒体引用。

## 验收标准

| ID       | 验收场景       | 通过条件                                                                                                                         |
| -------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| M6-AC-01 | 多目标任务     | 为两个不同目标创建发布任务后，任务分别呈现内容形态、目标账号、状态与结果；一个目标失败不改变另一个任务记录。                     |
| M6-AC-02 | 分形态能力     | 测试平台支持图文但不支持视频；图文任务可进入自动发布，视频任务不得显示自动发布可用，并给出准确原因和替代路径。                   |
| M6-AC-03 | 发布前确认     | 未确认最终内容包/账号时不能执行外部发布；确认界面展示形态、正文或媒体文件/顺序/封面，并与实际执行目标一致，可取消。              |
| M6-AC-04 | 人工发布路径   | 对声明不支持或未验证自动发布的平台，可创建人工任务并导出完整发布包、打开目标平台；视频/图文的多媒体信息不丢失，状态可完成/取消。 |
| M6-AC-05 | 超时不确定     | 模拟请求超时且无法确认平台结果，任务进入可核对状态；系统不会自动重复提交，用户可查询或标记核对结果。                             |
| M6-AC-06 | 结果持久化     | 成功/失败任务均保留形态、内容版本、目标、时间、结果/原因；成功时保存适配器返回的外部 ID/URL（若平台提供）。                      |
| M6-AC-07 | 分形态作品同步 | 导入视频、图文和文章作品后，Content 列表可按四种形态、平台、账号、时间、状态和关键词筛选；详情展示来源、原始类型和外部 ID。      |
| M6-AC-08 | 同步幂等       | 对相同来源数据重复运行同步，不产生重复作品；重复快照是否记录遵循明确的采样策略。                                                 |
| M6-AC-09 | 指标口径       | 视频播放与文章阅读等同名或异名指标保留原始名称、形态、采集时间和定义；无统一定义时不聚合为可误读的总数。                         |
| M6-AC-10 | 趋势与筛选     | 对有至少两个采样点的测试账号/作品，按日/周/月展示可追溯趋势；无数据或口径不可比时明确提示，而非伪造零值。                        |
| M6-AC-11 | Dashboard      | 展示平台/账号数量、最近发布、待处理任务、同步异常和近期作品；平台、账号、内容形态、时间筛选对相应卡片/列表生效。                 |
| M6-AC-12 | 账号失效恢复   | 同步检测账号无效后提示重新授权，暂停依赖该账号的任务；重新授权后允许用户显式恢复或重试。                                         |
| M6-AC-13 | 视频发布往返   | 对支持视频的测试适配器提交视频、封面和元数据；Adapter 收到的 `ContentKind`、文件引用、封面和字段完整，结果可追溯且不重复上传。   |
| M6-AC-14 | 图文顺序与封面 | 对支持图文的测试适配器发布三张图片；接收顺序与用户设置一致，封面归属正确，人工发布包导出后仍保持相同顺序。                       |

## 不在本阶段

- 所有平台全量自动发布、保证平台开放全部指标、跨平台指标直接相加。
- 未经确认的批量发布或自动重试。
- 专业视频剪辑、转码工作台和图像处理。
- 复杂报表、归因建模和团队级权限。

## 测试与交付

交付分形态发布任务状态机、平台 × 内容形态能力矩阵、`PublishInput` 载荷规范、同步幂等与重试策略、指标字典和口径说明；覆盖多目标部分失败、分形态能力缺失、视频/图文发布包完整性、发布超时、重复同步、账号过期、指标缺失、迁移和异常恢复测试。
