# Platform logo assets

These are local copies of the platform websites' own favicon or app shortcut icon, so the
application never depends on a third-party CDN at runtime. The icons are intentionally kept in
their original colors and compositions; low-resolution site favicons are used only at UI sizes
that do not exceed their source resolution.
