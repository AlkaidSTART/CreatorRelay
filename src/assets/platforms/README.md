# Platform logo sources

The brand SVGs in this directory are vendored locally so the desktop UI does not depend on
third-party CDN availability or runtime network access.

- Bilibili, CSDN, Juejin, Kuaishou, Sina Weibo, WeChat, Xiaohongshu, YouTube, Zhihu:
  [Simple Icons](https://simpleicons.org/), CC0 1.0.
- Douyin: hand-authored SVG based on the platform's music-note mark, because Simple Icons
  does not currently publish a Douyin icon.

All names and marks belong to their respective owners and are used here only to identify the
supported publishing platforms.
